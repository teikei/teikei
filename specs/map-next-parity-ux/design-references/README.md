# Design references — NON-NORMATIVE

These screenshots are a **pre-rewrite design concept** ("ernte teilen", created in Zeplin by
a designer before the map-next rewrite started). They are kept as **inspiration for mood,
color, and design foundations only**.

**Do not implement these screens.** They are _not_ a design requirement, _not_ a layout
spec, and several features shown in them (news feeds, region/farm subscriptions, the header
navigation bar, the add-entry dropdown) are not part of the product scope. The actual
design direction — what to adopt from these images and what to ignore — is distilled in
[`../design-direction.md`](../design-direction.md), and the binding UX/feature scope lives
in [`../spec.md`](../spec.md) (Track C).

If a conflict arises: `spec.md` > `design-direction.md` > these images.
